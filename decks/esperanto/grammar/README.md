# Gramatiko

63 points where intermediate speakers hesitate, or carry over a habit from Spanish, English or German, each as a sentence with a choice. Part of the [Esperanto deck](../), in `Languages::Esperanto::04 Gramatiko`. The rules follow the *Fundamento de Esperanto* and Bertilo Wennergren's *Plena Manlibro de Esperanta Gramatiko* (PMEG).

Topics, each a tag (`topic::`): akuzativo (direction, time, measure, relative *kiun*), predikativo (*trovi ĝin enuiga*, *estas bele*), si (*sia*/*lia*), transitiveco (*komenci*/*komenciĝi*, *boli*/*boligi*), participoj, modoj (*-us*, *-u*, reported speech, *ĉu*/*se*), prepozicioj (*da*/*de*, *pro*/*por*, *je*, *ol*/*kiel*), korelativoj (*kiu*/*kio* after a noun or *ĉio*).

## Card

Note type **Esperanto Choice**, one card per note (*Elekti*):

- **Front:** the sentence with the options in brackets (*Ŝi trovis la filmon [enuigan / enuiga]*), in an order that doesn't give the answer away.
- **Back:** the correct sentence (spoken) and the rule.

## Editing

One sentence per line of `elektoj.txt`: `sentence with {{correct/wrong}} | rule | topic`. The first option is the correct one; there may be more than one wrong option. Then rebuild as in the [deck README](../README.md#editing-and-rebuilding).
